## How to host FREE

### Cloudflare Pages (recommended, custom domain free)
1. Create GitHub repo: anup-portfolio
2. Upload all 5 files to root
3. dash.cloudflare.com > Pages > Create project > Connect to Git > Select repo
4. Build settings: Framework preset = None, Build command = empty, Output = /
5. Deploy. You get anup-portfolio.pages.dev instantly.
6. Add custom domain in Pages settings.

### GitHub Pages
Settings > Pages > Source: Deploy from main / root > Save. Live at username.github.io/anup-portfolio

### Contact Form (no backend)
Replace https://formspree.io/f/your-id in contact.html with your real endpoint from formspree.io (free). Alternative: https://formsubmit.co/ — just use your email as action.

Enjoy. Keep it dark.
